# Sistem Informasi Perpustakaan Berbasis Java

## Deskripsi Proyek
Sistem Informasi Perpustakaan Berbasis Java merupakan proyek kelompok untuk mata kuliah Pemrograman Berorientasi Objek. Proyek ini bertujuan untuk membantu proses pengelolaan data perpustakaan melalui sebuah aplikasi yang dikembangkan menggunakan bahasa pemrograman Java.

## Tujuan Proyek
1. Menerapkan konsep Object-Oriented Programming (OOP) dalam Java.
2. Membuat sistem untuk membantu pengelolaan data perpustakaan.
3. Memahami penerapan class, object, inheritance, encapsulation, dan konsep OOP lainnya sesuai kebutuhan sistem.
4. Melatih kerja sama kelompok dalam proses perancangan dan pengembangan aplikasi.

## Fitur Sistem
- Pengelolaan data buku.
- Pengelolaan data anggota perpustakaan.
- Peminjaman dan pengembalian buku.
- Pencatatan transaksi perpustakaan.

*Catatan: Fitur akan disesuaikan dengan hasil perancangan dan implementasi proyek.*

## Teknologi yang Digunakan
- Bahasa Pemrograman: Java
- Konsep: Object-Oriented Programming (OOP)
- Repository: GitHub
